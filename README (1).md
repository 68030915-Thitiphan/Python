# คำอธิบายข้อมูล (Data Description)

โฟลเดอร์นี้อธิบายข้อมูลที่ใช้ในโครงงาน **IT Salary Analysis**

## 1. แหล่งที่มาและสิทธิ์การใช้ข้อมูล

| หัวข้อ | รายละเอียด |
| --- | --- |
| ชื่อชุดข้อมูล | Video Game Sales |
| แหล่งที่มาเดิม |[ https://www.kaggle.com/datasets/parulpandey/2020-it-salary-survey-for-eu-region ](https://www.kaggle.com/datasets/gregorut/videogamesales)|
| ผู้เก็บข้อมูล | Gregory Smith |
| ช่วงเวลาของข้อมูล | ปี ค.ศ. 2002 – 2016 (รวม 15 ปี) |
| ประเภทข้อมูล | สถิติยอดขายเกมแผ่นแบบเชิงตัวเลข 1 แถวต่อเกม 1 ปก |
## 2. ไฟล์ในโฟลเดอร์นี้

| ตำแหน่งไฟล์ | คำอธิบาย |
| --- | --- |
| `Downloads\project\Game_data.xlsx` | ไฟล์ดิบตามที่ดาวน์โหลดมา **ห้ามแก้ไขด้วยมือ** มี  16,598 แถว 11 คอลัมน์ |
| `Downloads\project\Game_data_clean.xlsx` | ข้อมูลที่ล้างแล้ว 2,490 แถว 8 คอลัมน์  |



## 3. พจนานุกรมข้อมูล (Data Dictionary) ของ `DATA_GAME_clean`

ข้อมูลหลังจากทำความสะอาดแล้วมีทั้งหมด 2,490 แถว ตารางต่อไปนี้แสดงชื่อคอลัมน์ ชนิดข้อมูล คำอธิบาย 
| คอลัมน์ | ชนิดข้อมูล | คำอธิบาย / รายละเอียด | หน่วย |
| :--- | :--- | :--- | :---: |
| `Platform` | ข้อความ | เครื่องเล่นเกมที่วางจำหน่าย (เช่น Wii, DS, X360, PS2, PS3, PC) | - |
| `Year` | ตัวเลข | ปี ค.ศ. ที่วางจำหน่ายเกม (ค.ศ. 2002–2016) | ค.ศ. |
| `Publisher` | ข้อความ | ค่ายเกมผู้จัดจำหน่าย รวมทั้งหมด 2,489 รายการ ได้แก่:<br>• Electronic Arts (EA): 1,157 เกม<br>• Ubisoft: 852 เกม<br>• Nintendo: 480 เกม | - |
| `NA_Sales` | ตัวเลขต่อเนื่อง | ยอดขายเกมในภูมิภาคอเมริกาเหนือ | ล้านชุด |
| `EU_Sales` | ตัวเลขต่อเนื่อง | ยอดขายเกมในภูมิภาคยุโรป | ล้านชุด |
| `JP_Sales` | ตัวเลขต่อเนื่อง | ยอดขายเกมในภูมิภาคญี่ปุ่น | ล้านชุด |
| `Other_Sales` | ตัวเลขต่อเนื่อง | ยอดขายเกมในภูมิภาคอื่นๆ ทั่วโลก | ล้านชุด |
| `Global_Sales` | ตัวเลขต่อเนื่อง | ยอดขายเกมรวมทั่วโลก | ล้านชุด |
